Privacy policy

Last updated: 23 November 2026

ClaudeYoutubeAnalyser is a personal tool. Its only user is the owner of the YouTube channel Ketab Goosh.

What it accesses

With the owner's consent, it uses the YouTube Data API and the YouTube Analytics API to read the channel's videos and statistics. If the owner separately grants it, it can also edit the channel's own video details.

How the data is used and stored

The data is used only to analyse and improve that channel. Data and sign-in tokens are stored on the owner's computer, and reports may be kept in the owner's private backup. The owner also uses Anthropic's Claude, an AI assistant, to analyse the channel data, so data may be processed by that service. The data is not sold or used for advertising.

Removing access and data

The owner can revoke access at any time at Google Account permissions and delete the local files.

The tool uses YouTube API Services: YouTube Terms of Service, Google Privacy Policy.
